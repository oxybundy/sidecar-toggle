# Changelog

## 2.0.0

- Settings window with **Open at login**, **Show in menu bar** and a shortcut recorder
- The menu bar icon can be hidden; open the app from Applications or Spotlight to get back to Settings
- New app icon and matching menu bar glyph
- Ships as a drag-to-Applications disk image, and offers to move itself into Applications if opened from it
- Universal build for Apple Silicon and Intel
